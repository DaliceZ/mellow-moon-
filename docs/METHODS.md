# วิธีอ่านของ Mellow Moon รุ่น 1

## ดวงรายวัน: personal-reflection-v2

คำอ่านเป็นกิจกรรมทบทวนตัวเองจากคลังข้อความที่เรียบเรียงไว้ ไม่ได้คำนวณดาวจรหรือดวงกำเนิด และไม่ใช่การทำนายทางวิทยาศาสตร์

แยกคลังข้อความ 16 ชุดสำหรับภาพรวม ความรัก งานและการเรียน การเงิน และการดูแลตัวเอง มี 7 ชุดเดิมตามสัญลักษณ์วันและ 9 ชุดเพิ่มเติม แต่ละหมวดเลือกแยกกัน หัวเรื่องสัมพันธ์กับข้อความภาพรวม

คีย์สำหรับเลือกคำอ่านประกอบด้วยเวอร์ชัน วันเดือนปีเกิดเต็ม ชื่อเล่นที่ normalize และวันที่อ่าน ใช้ FNV-1a 32-bit บน code point เพื่อเลือกดัชนีในคลังของแต่ละหมวดอย่างคงที่ เป็นกฎเลือกเนื้อหาของโปรเจกต์ ไม่ใช่สูตรโหราศาสตร์ การเปลี่ยนข้อมูลโปรไฟล์อาจเปลี่ยนคำอ่าน ข้อมูลเดียวกันและวันเดียวกันจะได้ผลเหมือนกันข้ามอุปกรณ์ ไม่มีการสุ่มใหม่เมื่อรีเฟรช

ผู้ไม่มีวันเกิดใช้ UUID ผู้เยี่ยมชมที่เก็บไว้ในเบราว์เซอร์ร่วมกับชื่อเล่น ทำให้ผู้เยี่ยมชมคนละเบราว์เซอร์มีคีย์แยกกัน ผู้มีโปรไฟล์วันเกิดเดียวกันและชื่อเดียวกันใช้คีย์เดียวกัน และผู้ใช้คนละคีย์ยังมีบางประโยคหรือธีมตรงกันได้เพราะใช้คลังข้อความร่วมกัน ไม่มีการอ้างว่าเนื้อหาทุกคำจะไม่ซ้ำกันระหว่างผู้ใช้

วันในสัปดาห์และสีประจำวันยังใช้ปฏิทินของอุปกรณ์ รายสัปดาห์และรายเดือนรวมคำอ่านเฉพาะบุคคลของแต่ละวันตามปฏิทิน ID บันทึกดวงรุ่นนี้แยกตามเวอร์ชัน วันที่ และ personKey ไม่ปะปนกับคำอ่านรุ่นเก่าหรือโปรไฟล์อื่น

## การจัดการวันเกิด

ตรวจรูปแบบ YYYY-MM-DD และตรวจวันที่ย้อนกลับเพื่อไม่ยอมรับวันที่ที่ JavaScript normalize เช่น 30 กุมภาพันธ์ ใช้ local noon หลีกเลี่ยงปัญหา parse ISO date เป็น UTC ไม่มีการแปลงเขตเวลาประวัติศาสตร์เพราะรุ่นนี้ไม่รองรับเวลาเกิด/ลัคนา

ราศีใช้ช่วงวันที่ tropical zodiac แบบทั่วไป ไม่ใช่ตำแหน่งดวงอาทิตย์ที่คำนวณจริงในปีเกิด ข้อมูลนี้แสดงในหน้าป้อนวันเกิดพร้อมข้อจำกัด และไม่ได้ใช้สร้างคำทำนาย

## ไพ่ทาโรต์

สำรับประกอบด้วย Major Arcana 22 ใบ และ 4 ชุด ชุดละ 14 ใบ ใช้ stable ID 0..77 เดิมเพื่ออ่านบันทึกเก่าได้ โดย Strength เป็น VIII และ Justice เป็น XI

เนื้อหา `rws-reflection-th-2` อยู่ใน `src/features/tarot/content.ts` แยกจาก engine (`interpretation.ts`), metadata และการจับ (`deck.ts`), ภาพ (`TarotArt.tsx`) และหน้าอ่าน (`ReadingMeaning.tsx`) ทุกใบมีเรื่องราวหัวตั้ง สิ่งที่ติดขัด/คลี่คลายเมื่อกลับหัว มุมความรัก มุมงานและการเรียน สัญลักษณ์ ธีม คำถาม และสิ่งที่ลองทำได้ ซึ่งเขียนแยกใบ ไม่ใช้แม่แบบลำดับไพ่แทนความหมายเฉพาะ

ใช้ [The Pictorial Key to the Tarot ของ A. E. Waite](https://sacred-texts.com/tarot/pkt/index.htm) เป็นแหล่งอ้างอิงภาพและสัญลักษณ์ของ RWS ภาษาไทยและคำแนะนำเป็นการเรียบเรียงใหม่เพื่อทบทวนตัวเอง แนวกลับหัวของเว็บอ่านผ่านการติดขัด การใช้มาก/น้อยเกินไป หรือการเริ่มคลี่คลาย ไม่อ้างว่าเป็นคำแปลตรงของตำราหรือกฎสากล

คำอ่านร่วมใช้ตำแหน่งที่ผ่านมา/ตอนนี้/ทางที่อาจลอง คู่ไพ่ที่เขียนไว้เฉพาะ ธีมต้นและท้าย ธีมซ้ำ ชุดที่มีสองใบขึ้นไป สัดส่วน Major Arcana และ orientation เลือกเนื้อหาแบบ deterministic ไม่มีการเรียกบริการสร้างคำอ่านระหว่างใช้งาน คู่ที่ไม่มีข้อความเฉพาะใช้การเปลี่ยนธีมและคำถามตามตำแหน่งเป็น fallback ไม่รับรองเหตุการณ์ในอนาคต

การบันทึกเก็บข้อความคำอ่านทั้งชุดตามมุมที่เลือก พร้อมบันทึกความรู้สึกส่วนตัวใน snapshot ส่วนการคัดลอกคำอ่านไม่รวมบันทึกความรู้สึก
วิธีจับ: สร้าง array 0..77 ใช้ Fisher–Yates จากท้ายไปหน้า เลือก integer ด้วย Web Crypto Uint32 โดย rejection sampling ตัดส่วนเกินที่หารจำนวนทางเลือกไม่ลงตัวออก จับตามจำนวนที่เลือกโดยไม่คืนไพ่ จึงไม่ซ้ำในชุด ไพ่กลับหัวใช้ integer 0/1 เมื่อผู้ใช้เปิดตัวเลือก

การสุ่มใช้เฉพาะกิจกรรมจับไพ่เพื่อความเพลิดเพลิน session มี UUID วันที่ mode ไพ่ orientation และตำแหน่งที่เปิดแล้ว บันทึก localStorage ทันที การรีเฟรชและเปลี่ยนหน้าไม่จับใหม่ เริ่มรอบใหม่ต้องยืนยันการทิ้งโต๊ะปัจจุบัน

ไพ่หนึ่งใบสะท้อนเรื่องที่นึกถึง ไพ่สามใบใช้ “ที่ผ่านมา / ตอนนี้ / ทางที่อาจลอง” โหมดความรักและงานเลือกมุมคำอ่านเริ่มต้น และเปลี่ยนมุมหลังเปิดไพ่ได้โดยไม่จับใหม่ ไม่ทำนายความรู้สึกของผู้อื่นหรือรับประกันอนาคต ไม่มี Yes/No หรือคะแนนความแม่นยำในรุ่นนี้

## สีประจำวัน

ใช้ลำดับสีที่พบในธรรมเนียมไทย: อาทิตย์แดง จันทร์เหลือง อังคารชมพู พุธเขียว พฤหัสบดีส้ม ศุกร์ฟ้า เสาร์ม่วง เฉดที่แสดงเป็นงานออกแบบใหม่ ไม่ได้แบ่งเป็นสีเรียกเงิน ความรัก หรือสุขภาพ
