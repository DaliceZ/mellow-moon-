# วิธีอ่านของ Mellow Moon รุ่น 1

## ดวงรายวัน: weekday-ruler-v1

นี่เป็นกิจกรรมทบทวนตัวเองจากสัญลักษณ์ของดาวประจำวัน ไม่ใช่เครื่องคำนวณดาวจรหรือดวงกำเนิด

วันที่อ่านแปลงเป็นวันในสัปดาห์ด้วย local calendar ของอุปกรณ์ แต่ละวันเลือกธีมและเนื้อหา 5 หมวดจากตารางใน `src/lib/fortune.ts`:

| วัน | สัญลักษณ์ | ธีม |
|---|---|---|
| อาทิตย์ | Sun | ความเชื่อมั่น การเริ่มจากตัวเอง |
| จันทร์ | Moon | ความรู้สึก การดูแลใจ |
| อังคาร | Mars | การลงมือ จัดการแรง |
| พุธ | Mercury | การสื่อสาร ตรวจรายละเอียด |
| พฤหัสบดี | Jupiter | การเรียนรู้ ขอคำแนะนำ |
| ศุกร์ | Venus | ความสุข ความสัมพันธ์ |
| เสาร์ | Saturn | ขอบเขตและการจัดระเบียบ |

ใช้การเชื่อมโยงดาวกับวันในระบบ planetary weekdays เป็นพื้นฐานของงานเขียน ไม่ได้นำดาวจรจริงมาใช้ เนื้อหาทุกหมวดเขียนไว้ใน source ไม่มีการประกอบจาก LLM ระหว่างใช้งาน วันเกิดเลือกข้อความเสริมหนึ่งข้อความตามวันในสัปดาห์ที่เกิด ข้อความเหล่านี้เป็น editorial rules ของโปรเจกต์ ไม่ใช่คัมภีร์พยากรณ์ที่ผ่านการรับรอง

ข้อมูลเหมือนเดิม วันที่เหมือนเดิม จะได้ผลเดิม ธีมซ้ำทุก 7 วัน รายสัปดาห์แสดงวันจันทร์ถึงอาทิตย์ของสัปดาห์นั้น รายเดือนแสดงวันที่ทั้งหมดในเดือนนั้น ส่วนหัวใช้ธีมของวันที่เลือก ไม่อ้างเป็นพยากรณ์รวมใหม่

## การจัดการวันเกิด

ตรวจรูปแบบ YYYY-MM-DD และตรวจวันที่ย้อนกลับเพื่อไม่ยอมรับวันที่ที่ JavaScript normalize เช่น 30 กุมภาพันธ์ ใช้ local noon หลีกเลี่ยงปัญหา parse ISO date เป็น UTC ไม่มีการแปลงเขตเวลาประวัติศาสตร์เพราะรุ่นนี้ไม่รองรับเวลาเกิด/ลัคนา

ราศีใช้ช่วงวันที่ tropical zodiac แบบทั่วไป ไม่ใช่ตำแหน่งดวงอาทิตย์ที่คำนวณจริงในปีเกิด ข้อมูลนี้แสดงในหน้าป้อนวันเกิดพร้อมข้อจำกัด และไม่ได้ใช้สร้างคำทำนาย

## ไพ่ทาโรต์

สำรับประกอบด้วย Major Arcana 22 ใบ และ 4 ชุด ชุดละ 14 ใบ ชุดใหญ่มีความหมายและคำถามแยกใบ ชุดเล็กมีเนื้อหาประจำชุดร่วมกับขั้นของไพ่ลำดับนั้น ภาพชุดเล็กใช้จำนวนสัญลักษณ์ ชุด และอันดับบุคคล ภาพชุดใหญ่ตีความใหม่ด้วยตัวละครและสัญลักษณ์ในโทนเดียวกัน

วิธีจับ: สร้าง array 0..77 ใช้ Fisher–Yates จากท้ายไปหน้า เลือก integer ด้วย Web Crypto Uint32 โดย rejection sampling ตัดส่วนเกินที่หารจำนวนทางเลือกไม่ลงตัวออก จับตามจำนวนที่เลือกโดยไม่คืนไพ่ จึงไม่ซ้ำในชุด ไพ่กลับหัวใช้ integer 0/1 เมื่อผู้ใช้เปิดตัวเลือก

การสุ่มใช้เฉพาะกิจกรรมจับไพ่เพื่อความเพลิดเพลิน session มี UUID วันที่ mode ไพ่ orientation และตำแหน่งที่เปิดแล้ว บันทึก localStorage ทันที การรีเฟรชและเปลี่ยนหน้าไม่จับใหม่ เริ่มรอบใหม่ต้องยืนยันการทิ้งโต๊ะปัจจุบัน

ไพ่หนึ่งใบสะท้อนเรื่องที่นึกถึง ไพ่สามใบใช้ “ที่ผ่านมา / ตอนนี้ / ทางที่อาจลอง” โหมดความรักและงานเพิ่มคำถามตามเรื่อง ไม่ทำนายความรู้สึกของผู้อื่นหรือรับประกันอนาคต ไม่มี Yes/No หรือคะแนนความแม่นยำในรุ่นนี้

## สีประจำวัน

ใช้ลำดับสีที่พบในธรรมเนียมไทย: อาทิตย์แดง จันทร์เหลือง อังคารชมพู พุธเขียว พฤหัสบดีส้ม ศุกร์ฟ้า เสาร์ม่วง เฉดที่แสดงเป็นงานออกแบบใหม่ ไม่ได้แบ่งเป็นสีเรียกเงิน ความรัก หรือสุขภาพ
