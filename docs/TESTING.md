# ผลตรวจรุ่นแรก

ตรวจวันที่ 4 พฤศจิกายน 2569 ด้วย Node 22.22.2 บน Ubuntu WSL และ Chromium ของ Playwright

## ผ่าน

- TypeScript และ production build (`npm run build`)
- Unit tests 29 ข้อ (`npm test`): ขอบราศีแบบประมาณ วันที่ผิด/อธิกสุรทิน ปี พ.ศ. วันเกิด ความคงที่ของคำอ่าน กฎตามวัน สีประจำวัน สำรับ 78 ใบ ไพ่ไม่ซ้ำ และ orientation
- Playwright 3 ชุด (`npm run test:e2e`): กรอกโปรไฟล์ คำอ่านไม่เปลี่ยนเมื่อรีเฟรช รายสัปดาห์มี 7 วัน เปิดไพ่ 3 ใบไม่ซ้ำและอยู่ครบเมื่อรีเฟรช บันทึกคำอ่าน เพิ่ม/ลบบันทึกและยกเลิกการลบ ความผิดพลาดเมื่อบันทึกว่าง checkbox กิจวัตรคงอยู่ เลือกสี และหน้า methods
- ตรวจ overflow ที่ 1440×1100, 375×812, 812×375 และตรวจทั้งห้าหน้าหลักที่ 375×812
- Axe WCAG 2 A/AA และ 2.1 AA บนหน้าบ้าน ดวง ไพ่ สี และสมุด ในสถานะเริ่มต้น ไม่พบ violations
- เปิด modal จากเมนูมือถือและปิดด้วย Escape
- ตรวจเปิดใช้งาน reduced motion
- ไม่พบ uncaught page errors ในโฟลว์หลัก
- `npm audit --omit=dev`: 0 vulnerabilities ณ วันที่ตรวจ; การติดตั้งหลังอัปเดต dependency ทั้งหมดรายงาน 0 vulnerabilities เช่นกัน
- ตรวจภาพหน้าแรกด้วยสายตาบนพรีวิว และ screenshots desktop/mobile

## ข้อจำกัดการตรวจ

Axe ไม่รับประกัน accessibility ทุกกรณี ยังไม่ได้ทดสอบกับโปรแกรมอ่านหน้าจอจริงหรือทุกสถานะของไพ่/ฟอร์ม ยังไม่ได้ทดสอบ Safari, Firefox, cross-device sync หรือข้อมูลหลายปี ไม่มีระบบเวลาเกิด เขตเวลาประวัติศาสตร์ หรือคำนวณดาวในรุ่นนี้

ภาพ QA เก็บที่ `output/home-1440.png`, `output/home-375.png`, `output/home-812.png` ใน checkout นี้ ไม่รวมใน source ที่เผยแพร่

## อัปเดต UX มือถือและสมุดภาพ

- Unit tests 31 ข้อ รวมการเรนเดอร์ไพ่ 78 ใบและการอ่านภาพไพ่จากบันทึกรุ่นเดิมโดยรักษาลำดับไพ่
- E2E 4 ชุด รวมการพาไปหมวดสมุดทันทีหลังบันทึก toast ไม่เพิ่มข้อมูลซ้ำ และทางลัดมือถืออยู่ในหน้าจอแรก
- ตรวจสมุดทั้งหน้าว่างและหน้าที่มีไพ่ ดวง และบันทึก พร้อม Axe WCAG A/AA
- ตรวจภาพหน้าแรกมือถือ สมุดมือถือ/desktop และ contact sheet ไพ่ 78 ใบ
- ย้ายข้อความอธิบายที่ไม่จำเป็นออกจากทางเดินหลักของผู้ใช้

## ไพ่ผลทำนายแบบ 3D

- เปลี่ยนไพ่ตรงหน้าผลทำนายเป็น CSS 3D มีหน้า หลัง ชั้นขอบไพ่ แสงเคลือบและประกายฟอยล์ตามมุมหมุน
- ลากหมุนได้ครบ 360° ใช้ปุ่มหรือลูกศรคีย์บอร์ดเพื่อหมุน เอียง และคืนมุมมองได้ โดยไม่เปลี่ยนคำอ่านหรือสถานะไพ่กลับหัว
- Production build ผ่าน; unit tests 31 ข้อ และ E2E 5 ชุดผ่าน
- E2E ตรวจหมุนหน้า/หลัง/ครบวง ลากด้วยเมาส์ คีย์บอร์ด เปิดปิดฟอยล์ reduced motion ความกว้างมือถือ Axe และการบันทึกลงสมุด
- ตรวจภาพที่ `output/tarot-3d-desktop.png` และ `output/tarot-3d-mobile.png`; ยังไม่ได้ทดสอบ Safari หรือสัมผัสบนอุปกรณ์จริง


## คำอ่านเฉพาะทั้ง 78 ใบ

- Production build ผ่าน, unit tests 36 ข้อและ E2E 6 ชุดผ่านบน Chromium
- ตรวจความครบและไม่ซ้ำของเนื้อหา 7 ฟิลด์ตลอด 78 ใบ, ตำแหน่ง Strength/Justice, ความหมายสามถ้วย/สามดาบ/สามเหรียญ
- ตรวจ orientation, การสลับมุมอ่านโดยไม่เปลี่ยนไพ่, ตำแหน่งที่ต่างกัน, คู่ไพ่เฉพาะและธีมชุดไพ่
- ตรวจบันทึก snapshot คำอ่านร่วมและความรู้สึกลงสมุด และอ่านกลับหลังรีเฟรช
- Axe ในหน้าผลสามใบที่มีหัวตั้งและกลับหัวไม่พบ WCAG A/AA violations; ตรวจ overflow ที่ 375px และภาพ desktop/mobile
- ยังไม่ได้ทดสอบการสัมผัสบนอุปกรณ์จริงหรือโปรแกรมอ่านหน้าจอจริง


## สมุดอ่านฉบับเต็มและคำอ่านตามโปรไฟล์

- สมุดมีปุ่มเปิดอ่านฉบับเต็มสูงอย่างน้อย 44px และแตะภาพเพื่อเปิดได้
- หน้าต่างอ่านแยกหัวข้อกับคำตอบ รองรับบันทึกเก่า และกรองคำถามที่เลิกใช้ 3 ข้อออกจากคำอ่านที่แสดง
- ปิดด้วย Escape/ปุ่มกลับ และคืน focus ไปปุ่มที่ใช้เปิด; Axe WCAG A/AA ในหน้าต่างอ่านบนมือถือผ่าน
- เอาชุดปุ่มหมุน เอียง รีเซ็ต และข้อความ/ปุ่มฟอยล์ตามภาพออก; ลากและคีย์บอร์ดยังหมุนไพ่ได้
- Unit tests 38 ข้อผ่าน รวมความคงที่ของคำอ่านและความต่างเมื่อวันเกิดตรงวันในสัปดาห์เดียวกัน
- E2E ตรวจสอง browser contexts ที่มี guest ID ต่างกัน รีเฟรชแล้วคงเดิม โปรไฟล์ต่างกันได้ชุดคำอ่านต่างกัน และโปรไฟล์เหมือนกันได้ผลตรงกันข้ามเบราว์เซอร์
- ตรวจภาพสมุด ปุ่มเปิดอ่าน หน้าต่างอ่าน และหน้าดวงรายวันบนมือถือ

- ตรวจชุดสุดท้ายหลังแก้การคืน focus: production build, unit tests 38 ข้อ และ E2E ทั้ง 8 ชุดผ่าน


## ความอ่านง่ายของดวงรายวัน

- จัดหัวอ่านเป็นเจ้าของคำอ่าน หมวด และวันที่ในกลุ่มเดียวกัน พร้อมจำกัดเนื้อหาไม่เกิน 640px
- เพิ่มคำแนะนำ “ลองทำวันนี้” แยกตาม 5 หมวดและสัมพันธ์กับเนื้อหาที่เลือก เก็บไปพร้อมคำอ่านในสมุด
- เอาข้อความเตือนทั่วไปใต้คำอ่านออกจากหน้าดวง และจัดปุ่มเก็บ/อ่านที่มาอยู่ใกล้เนื้อหา
- Unit tests 39 ข้อผ่าน; E2E สมุด/โปรไฟล์/การอ่าน 3 ชุดผ่าน รวมทุกหมวด ความกว้าง 320 และ 375px, การบันทึกคำแนะนำ และ Axe WCAG A/AA
- ตรวจภาพ `output/readability-desktop.png` ที่ 1440px และ `output/readability-mobile.png` ที่ 375px
